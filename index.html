Spark — Local Idea Workbench

A local workbench for capturing ideas by text or dictation and testing them with models, built on Node and SQLite with zero dependencies. Anything a model writes stays a reviewable draft and can never fill an evidence field, and private entries never leave the computer.

  • Decision engine reads token probabilities instead of trusting a model's stated confidence; unsure captures are asked about, not guessed
  • 82-capture eval: cloud classifier 97.6% accurate vs 91.5% for the local model; paper relevance AUC 0.998
  • Cost router keeps private, structured and over-budget calls local: a heavy month measured at about $0.35

Agent Party — Dashboard for AI Coding Agents

A pixel-art dashboard that shows every AI coding agent on your machine: what it is doing, how much context it has left and what it costs. It reads Claude Code, Codex, Cursor, Gemini CLI, Cline, Aider and OpenCode sessions read-only, with one small adapter file per tool.

  • Flags agents that need you, are stuck in a loop, or are editing the same file as another agent
  • Approve Claude Code permission prompts from the dashboard or a paired phone
  • Zero dependencies: plain Node and one HTML file, run with npx agent-party-dashboard
