ZorAI

A decentralized provenance registry for AI-generated images, combining structured content analysis, IPFS metadata, and a durable public record on Base Sepolia.

The problem

AI-generated media can lose its creation context when copied. ZorAI explores an inspectable provenance claim that connects an image identifier to analysis metadata and an on-chain registration record.

What I built

  • Content-analysis workflow producing structured model and risk information.
  • IPFS metadata publishing plus deterministic image identifiers.
  • Solidity registry with register, read, and existence-check methods on Base Sepolia.
  • Server-side registration protected by an API key, alongside MetaMask client support.

Architecture

Image → content analysis → metadata on IPFS → Base Sepolia registry └──────────── deterministic identifier ────────────────┘ Verification request → contract read → provenance record

Security boundaries

  • Kept signing keys out of public environment variables and documented dedicated test-wallet use.
  • Separated server-signed registration from public verification reads.
  • Clearly scoped the claim: an unregistered image is not automatically authentic.

Outcome

The project demonstrates an end-to-end web3 workflow across UI, API routes, IPFS, wallet interaction, deployment tooling, and a publicly inspectable contract.
