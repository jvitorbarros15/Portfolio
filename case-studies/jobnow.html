JobNow

An AI job-search copilot that brings recruiter email, reminders, professional writing, job discovery, and tailored resume generation into one workspace.

The problem

A job search spreads work across email, calendars, spreadsheets, job boards, writing tools, and resume files. JobNow explores one workflow that turns those disconnected steps into reviewable actions.

What I built

  • A tracker that imports recruiter email, classifies it with Claude, creates calendar reminders, and updates application data.
  • A writing module that turns current technology news into three editable LinkedIn post drafts.
  • A job-search module that aggregates openings and creates a role-specific LaTeX resume.
  • Supabase authentication and PostgreSQL-backed application state.

System shape

Gmail → Claude classification → Calendar / Sheets / Supabase News APIs → editable professional drafts Job APIs + candidate data → tailored LaTeX resume

Engineering decisions

  • Generated structured LaTeX rather than returning unformatted LLM prose.
  • Kept provider aggregation and AI requests on server routes.
  • Designed AI outputs for user review and editing instead of automatic publication or application.

Scope

The public deployment is a portfolio demo. Google and job-provider workflows depend on valid OAuth credentials, API quotas, and each provider’s availability.
