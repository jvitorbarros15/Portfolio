Cognitra

An AI learning workspace that turns classes, notes, and lecture audio into connected study material instead of isolated outputs.

The problem

Study tools often generate disconnected summaries or flashcards. Cognitra organizes AI capabilities around the student’s class workflow so captured material remains connected to its source and can be revisited in multiple forms.

What I built

  • Class workspaces with cloud-backed notes and authenticated user data.
  • Protected lecture transcription supporting language detection, speaker labels, chapters, and highlights.
  • AI-generated flashcards and study material grounded in a learner’s notes.
  • Interactive concept maps built with React Flow and localized English/Portuguese UI.

Product workflow

Create class → notes or lecture audio → transcribe and organize → connect concepts → generate material → review

Engineering decisions

  • Kept OpenAI and AssemblyAI credentials on server routes rather than exposing them in browser configuration.
  • Used Firebase for authentication and cloud data so learning content follows the signed-in student.
  • Designed individual AI features as stages in one workflow rather than unrelated demos.

Verification

The project includes documented lint and production-build checks, explicit environment configuration, and a recruiter-facing public deployment.
