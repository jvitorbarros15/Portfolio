Meridian

A multi-market investment dashboard for Brazilian stocks and FIIs, U.S. equities, and cryptocurrency, with reproducible local infrastructure.

The problem

Investment data is often fragmented by country and asset class. Meridian explores how one product can normalize holdings, market refreshes, returns, watchlists, and alerts without hiding the infrastructure needed to keep that data coherent.

What I built

  • Next.js 16 and React 19 interface for portfolio, holdings, watchlists, alerts, and market data.
  • Asynchronous FastAPI service with SQLAlchemy, JWT authentication, and interactive API documentation.
  • PostgreSQL persistence, Redis caching, and yfinance-based market ingestion.
  • Docker Compose environment with local demo credentials and repeatable setup.

Architecture

Next.js / React ↓ REST FastAPI ↙ ↘ PostgreSQL Redis ← yfinance

Engineering decisions

  • Kept market ingestion behind the API so the interface does not own provider logic.
  • Used Redis for data that benefits from short-lived caching while preserving durable portfolio state in PostgreSQL.
  • Containerized every dependency so reviewers can run the same topology locally.

Verification

The repository documents frontend tests, linting, and production builds, alongside an on-demand market refresh endpoint and generated FastAPI documentation.
